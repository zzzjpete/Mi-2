# 模块索引

`scripts/` 下 **79 个脚本**逐个一行说明，按功能分组。这是一份**索引，不改变文件位置**。

> ⚠ **`scripts/` 不分子目录、不改文件名。**
> 脚本之间用 `_load_by_path(模块名, 文件名)` 按**同目录文件名**动态加载（全仓 111 处调用，
> 散在 29 个文件里），另有 11 个交付包内的 106 份副本受 MD5 与依赖闭合校验。
> 移动或改名的代价是同时搞坏验证与交付包，而且**改错不会在导入时报错，只在执行到那一行才炸**。
> 中文文件名必须按路径导入的原因见 [`工程笔记.md`](工程笔记.md) 一·6。

## 公共基础

| 脚本 | 说明 |
|---|---|
| `_medrag_root.py` | 项目根解析，让同一份代码在不同机器上都能跑：`MEDRAG_ROOT` → 从文件位置上溯找标志目录 → 兜底。解析不出来抛异常而不是返回一个不存在的路径（[工程笔记 一·10](工程笔记.md)） |
| `start_medrag.ps1` | 本地问答一键启动：起 Ollama、激活 conda 环境、打印命令菜单（仓库根目录，非 `scripts/`） |
