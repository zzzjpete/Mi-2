## 四、关键设计取舍

- **章节感知 + 递归兜底**：整篇 ≤512 token 不分割、整篇 1 块；长文先按顶层 `<sec>` 切，单章节 ≤512 整段成块，>512 再句子感知递归兜底 —— 既控长又尽量不打断语义单元。
- **doc_id 用 pmcid**：PMC 唯一登录号，100% 完整且全库唯一（pmid 存在缺失/不唯一，不适合当主键）。
- **用 bge-m3 分词器计长**：与后续 embedding 阶段对齐 token 口径（一处已知小尾巴：bge-base 换 BERT 分词器后约 4.3% 块会超 512 被截尾，见 `任务4/README.md`）。
