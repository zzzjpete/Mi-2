# 阶段九 · 强约束规则开发与幻觉抑制

> 阶段七把生成链跑通、阶段八让答案质量可测量，但两者的约束都是**建议式**的：
> 提示词里写着"只能引用真实存在的编号"，却没有机制保证模型照做，也没有办法判定
> "这一次到底守没守"。本阶段把硬约束写成分层指令，并且**在生成之后逐条判定、不合规就修**。

## 二、四层约束长什么样

```
┌─ 层 A 硬约束（系统提示词最前面）───────────────────────────┐
│ 1 知识库边界   答不出就原样写「根据现有文献无法回答此问题」 │
│ 2 引用来源     每个事实句挂 [S#]，只能用真实存在的编号      │
│ 3 禁止编造     证据里没有的数据/结论/细节一律不写           │
│ 4 术语规范     缩写首次出现给全称                           │
│ 5 输出格式     四个固定章节标题，语言与提问一致             │
└──────────────────────┬────────────────────────────────────┘
                       │
┌─ 层 B 角色与写作要求（阶段七四段原文，未改）──────────────┐
│ ①证据评估员 ②答案作者 ③批判审稿人 ④最终定稿人             │
└──────────────────────┬────────────────────────────────────┘
                       │
┌─ 层 C 输出骨架（写在用户消息里，给模型一个可填的模板）────┐
│ ## 核心答案 / ## 证据总结 / ## 证据强度与局限 / ## 参考文献 │
└──────────────────────┬────────────────────────────────────┘
                       ▼
              ④定稿 ─▶ ┌─ 层 D 校验与修正（代码，不是提示词）─┐
                       │ 1 六组检查 → 违规清单                │
                       │ 2 确定性修正（免费）→ 复检           │
                       │ 3 仍不合规 → 回灌违规清单让模型重写   │
                       │ 4 再确定性修正 → 复检；修坏了回退     │
                       └──────────────┬───────────────────────┘
                                      ▼
                        answer + constraint_check + constraint_repair
```

**为什么层 D 不能省**：提示词是概率性的，不是编译期约束。层 A 只能提高遵守率，
层 D 才能给出"这次到底守没守"的判定——本阶段的实测就是把这两件事分别量出来
（见「三」的第 2、3 列，它们来自**同一次生成**）。

六组检查与五块约束是**成对**的，写不进校验器的约束等于许愿：

| 硬约束 | 兜底的校验项 |
|---|---|
| 知识库边界 | `refusal.missing`、`refusal.conflict`（另有 `refusal.over_refusal` 抓过度拒答） |
| 引用来源 | `citation.invalid_number`、`citation.nonstandard_form`、`citation.missing` |
| 禁止编造 | `numeric.ungrounded`、`reference.fabricated`、`reference.altered` |
| 术语规范 | `terminology.missing_expansion`（表外缩写只报 `unknown_abbrev`/low） |
| 输出格式 | `structure.missing_section`、`structure.wrong_section_name`、`reference.incomplete` |

### 2) 层 D（校验 → 修正）到底修掉了什么

| 项 | 实测 |
|---|---|
| 修正前违规合计 | 6 条 |
| 修正后违规合计 | 3 条（消除 50%） |
| 被修成合规的用例 | `adv-A2`、`adv-B1`、`adv-C2` |
| 动用模型修正的用例 | 5 道（A2 / B1 / B3 / C2 / E1） |
| **只靠确定性修正就解决的用例** | **0 道** |
| 修正后违规反而增加而回退的 | 0 道 |

**"确定性修正一次都没单独派上用场"这条值得说清楚**：受约束组本来就没写出越界编号、
没用走样的标题——**能被正则修的那类问题，被层 A 在上游挡住了**。它的价值要到基线那种输出上
才体现（离线验证 H 组用真实的坏答案量过：一次确定性修正把 high 违规清零）。这正说明两层是
互补的，不是重复：层 A 降低出错率，层 D 兜住剩下的。

### 3) 代价

| 项 | 基线 | 受约束 |
|---|---|---|
| 模型调用 | 52 次 | 57 次（+5 次修正） |
| prompt token 合计 | 183,277 | **257,014（+40%）** |
| 输出 token 合计 | 30,098 | 28,851 |
| 墙钟（并发 4） | 411.3 s | 412.5 s |
| 单题耗时中位 | 124.5 s | 118.9 s |

约束层给每个写答案的段加了约 1,100 token 的系统提示词，**输入侧涨了四成**；
但输出没变长、墙钟几乎没动（411.3 → 412.5 秒）——本机瓶颈在解码不在预填充，
5 次修正调用摊进 13 道题的并发里也没顶出来。**结论：这套约束的成本主要是上下文预算，不是时间。**

### 4) 唯一的 FAIL：过度拒答 1/4（`adv-E1`）

判定 12/13 通过，未通过的那条是「受约束组对可答的题不过度拒答」。看答案本身：

> ## 核心答案
> 根据现有文献无法回答此问题。提供的文献片段未直接提及……仅涉及部分相关技术如 GUIDE-seq 和 T7E1 等方法。
> ## 证据总结
> - 有研究使用 GUIDE-seq 方法检测 CRISPR-Cas9 引起的脱靶效应…… [S2]
> - T7E1 试验被用于检测…… [S1]
> - 通过分子动力学模拟研究碱基错配的影响…… [S5]

它**其实答了**，三条都带出处，只是开头挂了拒答短语。为什么会这样：我在硬约束 1 里写了
「只能回答一部分时：先写出该句，再写可以回答的部分」，而判分口径是
「expect_refusal=False 的题上出现该短语即记误拒」。**是我自己的提示词与判分口径不一致**，
不是模型没守规矩——模型恰恰是照着提示词做的。

两条候选修法，各有代价，**改哪条都必须重新测一遍**：

1. **改提示词**：只有完全答不出才写该短语，部分可答就直接答、另说明哪部分没证据。
   代价：B2/B3/D2 这类"半可答"的题可能不再拒答，拒答率 1.0 会掉。
2. **改口径**：把「拒答短语 + 后续有带出处的实质内容」识别为**部分作答**，不计误拒。
   代价：一个"凡事先写拒答短语"的系统就再也抓不出来了。

我倾向第 2 条 + 单独统计"完全拒答／部分作答"两个数——因为**部分作答本来就是正确行为**，
只是当前的二值口径表达不了它。这是下一步的第一件事。

### 5) 2026-08-11：两条都做了（拒答拆三态）

**上面那两条修法最后都做了**，因为只做口径会留下一个假问题（模型仍然凡事先写拒答短语，
只是不再被记分），只做提示词又没法把"部分作答"这件事表达出来。

**新增 `PARTIAL_PHRASE`「现有文献仅能部分回答此问题」**，`kb_boundary` 从"一句拒答短语
包打天下"改成三选一：完全答不了 / 能答一部分（+「可以回答的部分：」「文献未涉及的部分：」）
/ 能完整回答。校验器出三态 `state`，`refusal.conflict` 阈值从 2 降到 1、可被确定性修正
（纯字符串把拒答短语换成部分作答短语，不调模型）。

#### ⚠ 误拒率 0.25 → 0.0 是怎么来的——必须照抄这句话

> **误拒率 0.25 → 0.0（判据修正：`adv-E1` 由「误拒」重新归类为「拒答短语与实质内容冲突」，
> 该类现由 `refusal.conflict` 检出并确定性修复）。新提示词的行为效果尚未验证。**

这个数是用 **`--rescore` 跑旧提示词下存的 26 份答案**得出的——**新提示词一个字都没参与**，
所以这个下降 **100% 来自判据重定义，不含任何行为改变**。
工具输出里也印了这段警告，避免以后有人把它读成"系统变好了"。

把"生成"与"判分"解耦：改一次口径不用重跑 26 次生成。**当天就靠它连抓两次我自己写错的口径**：

| 2 | 把证据总结也算进三态 | **9 道应拒题里 8 道被标成"部分作答"** | 强约束**本来就要求**拒答时也在证据总结里带出处列证据；`adv-A1` 问 2026 年获批药物，证据总结里是 MS 背景介绍 |

  它的问题是**表述自相矛盾**，不是能力被浪费）

两次都是一秒钟发现的。按老办法各要烧一轮 14 分钟 GPU。

#### 反向对照：`F_should_complete`（新增一类，与 `expect_refusal` 对称）

拆三态多出一个**新的失败方向**：把本可完整回答的问题降级成「仅能部分回答」。
原来 13 道题全在测"该拒的有没有拒"，**一条也测不到反方向**——本项目语料以综述为主，

的题（用例总数 13 → **19**），配 `complete_metrics()` 与独立判定项。

|---|---|

⚠ **两处必须如实记下来的**：

**① 出题两次错，系统两次对。** `adv-F5` 原本出在 live-3（那他珠单抗安全性），两版都被判降级。
查证据原文才发现：那篇产科结局综述**被检索到的是 Introduction 章节**，只有"动物研究报告
流产率增加"，具体结局在没被检索到的 Results 里。系统的部分作答**校准得很准**，还准确

只看标题会以为答得了，出不出得来题取决于检索块落在哪一节。**

**② 温度 0 不等于可复现。** 同一份代码、同一份证据连跑两轮，**9 道应拒题里 3 道的拒答形态

没动这几道的提示词。原因大概率是并发 4 下 Ollama 的批处理，加上层 D 的模型修正轮又是
一次生成。**后果：任何"全部为完全拒答"这类逐题全称判定，单跑一轮都不足以证明**，
要么多跑几轮，要么改成报占比。

#### 还没解决的：怎么判断一个"部分作答"是不是空洞的

这一轮 4 道部分作答里，**用带出处条数区分不开好坏**：

| 用例 | 条数 | 内容 | 判断 |
|---|---|---|---|
| `adv-A3` | 9 | FDA 适应症、获批日期、继 aducanumab 之后 | 好 |
| `adv-B3` | 1 | CLARITY-AD 入组 1795 人——**题目正是问入组人数** | 好 |
| `adv-A1` | 1 | "MS 是自身免疫病"、"1993 年以来 15 种 DMT"——**与"2026 年获批"无关** | 空洞 |

`B3` 一条却正中题意，`A1` 一条却答非所问。要判断被引内容**是否回应了本题**，
正则做不到——与前面三态口径撞的是同一堵墙。**这类不再用规则去解**，
归进「人群/终点匹配校验」一并考虑（它和"HFrEF 数据用来答 HFpEF"是同一类问题：
有出处、可溯源、完全合规，错的是适用性）。

**但其中可判的那一半已经解了：时间越界。** `refusal.beyond_evidence_year`——
问题里明确写出的年份 > **本次证据**的最大 `pub_year` 时，强制完全拒答，不允许部分作答。
纯元数据比较，不需要理解语义。

⚠ 界限必须用**本次证据**的最大年份，**不能用语料的**：`corpus_meta.json` 的
`pub_year.max` 是 2026，拿它当界限，`adv-A1`（问 2026 年获批）根本判不出来；
而它拿到的 live-3 证据最新只到 2024。

实测（19 道题全部重算，秒级，不需要 GPU）：**只打中 `adv-A1` 一道**。
`adv-A2` 问 2025 年、证据到 2023，但它**完全拒答了** → 不报（行为正确就不该报）；
`A3/B1/B3/E2` 那几个合理的部分作答问题里没有年份 → 不误伤。
提示词侧也加了同一条规则（硬约束 1 的 ① 分支），上游下游一致。

> ⚠ 时间越界这条是本轮 19 题跑完**之后**加的，所以上面那张表里的判定不含它。
> 用 `--rescore` 重算即可看到 `adv-A1` 命中——这正是把生成与判分解耦的价值。

#### 一条没有变成门禁的验收

「应拒题上必须全部为**完全**拒答」这条**没有做成 pass/fail**，只作为数字报出来
（报告表格、docx 表格、判定说明里都有完全/部分的构成）。原因是上面那条"温度 0 不可复现"：
9 道里 3 道在两轮之间翻转，5/9 与 6/9 之间没有信息量。**在把不确定性来源定位掉之前，
多跑几轮也只会得到三个都落在噪声里的数。** 真正守住的门禁是另外三条：
降级率 0/6、误拒率 0/10、守住边界率 9/9。

## 四、这一阶段踩到的坑（都是实测撞出来的）

**1. 引用准确率把参考文献列表里的编号也算进去了。** 参考文献一节是**代码生成**的，
每条开头都有 `[S#]`。把它们算进"引用总数"，等于用一堆必然正确的编号去稀释准确率——
阶段八那 4 份真答案，71 个编号里有 **22 个来自文献列表**，只有 49 个是正文引用。
**发现方式**：验证里那条"准确率与手算一致"对不上（手算 0.80，程序给 0.875）。
已改成先把参考文献一节挖掉再提编号。

**2. 同一处错误同时污染幻觉率与格式合规率。** `[S9]` 越界会触发 `citation.invalid_number`
（幻觉类），同时因为文献表里没有 S9 又触发 `reference.missing_entry`（格式类）——
一处错误被两个指标各扣一次，两个数就不再独立。已改成 `missing_entry` **只报本来存在、
却没列进文献表的编号**；越界编号交给幻觉类一家管。

**3. `self.check_numeric = bool(...)` 把同名方法覆盖掉了。** 构造参数与方法重名，
实例属性直接盖住类方法，调用时报 `'bool' object is not callable`。改叫 `enable_numeric`。

**4. 标题正则用 `\s*` 会把标题后面的空行吃掉。** `^\s*#{1,6}\s*(名称)\s*$` 里的 `\s`
匹配换行，替换标题时正文就粘到标题上了。前后一律改用 `[ \t]*`。

**5. 参考文献整段替换时，把后面的免责声明一起删了。** 参考文献通常是最后一节，
"从标题替换到下一个标题或文末"这个写法会连带扔掉挂在后面的 `> ⚠ 免责声明`。
已改成先把引用块行捞出来，替换完再接回去。

**6. 一条式的"宽松编号"正则会改坏正文。** 最初写成
`[\[\(（【]\s*(?:文献|来源|[Ss])?\s*(\d{1,3})\s*[\]\)）】]`，于是 `随访(24)周`、`分组(3)`
被当成无效引用**删掉**。改成三条分支：带前缀的任意括号、`[S1]` 这类、以及**只认方括号**的裸数字。

**7. CRISPR / Cas9 放进术语表，每份基因编辑答案都被判"缺全称"。** 要求模型写
"规律成簇间隔短回文重复序列（CRISPR）"纯属制造噪声。收录标准因此明确为
**"本领域当专名用、几乎从不展开"的排除掉**，sgRNA / PAM / HDR 这类留在表里。

**8. 标题归一必须受"确定性修正"开关管。** 后处理里顺手把 `## 回答` 改成 `## 核心答案`，
会把**对照组**的格式合规率自己抬上去，对比表当场失去意义。现在 `deterministic_fix=False`
时一个字都不改。

**9. 验证夹具里混进一条元数据残缺的文献，结果所有"应当合规"的断言全挂。** 那条 S3 在
真语料里确实没有期刊和年份，但把它放进"合规基线"夹具，测出来的全是夹具的问题、
不是被测代码的问题。已拆成两套夹具：干净的一套做基线，带缺陷的一套专供参考文献那一组。

## 五、关键设计取舍

**1. 出处编号继续用 `[S#]`，不改成任务书举例的 `[文献#]`。** 改前缀要连带改上下文组装器、
阶段七/八已落盘的全部快照与缓存键，收益却只是换个字面。**把兼容性放到校验器一侧**更划算：
模型写成 `[文献3]`/`[3]`/`【S3】` 时识别为"写法不规范但编号有效"，确定性改回 `[S3]`，不算编造。
顺手还覆盖了模型真实的写法漂移。

**2. 修正顺序是先确定性、后模型。** 编号写法、越界编号、章节标题、参考文献整段替换这些
不需要理解内容，正则改完就对，零成本零风险；剩下的（缺出处的句子、查不到的数字）才值得
花一次模型调用。反过来做的话，每次都要多烧一次模型去修本来正则就能修的东西。

**3. 修正后违规变多就回退。** 模型重写有可能引入新问题（实测见过把编号越写越多的）。
`enforce` 里比较修正前后的 high+medium 数，增加就退回上一版并记 `rolled_back`。

**4. `expect_refusal` 只喂校验器，绝不写进提示词。** 把答案先告诉模型再考它，测出来的
数字没有意义。

**5. 对照组（E 组）不是凑数。** 只看 A~D 的话，一个"什么都拒答"的系统能拿满分。
拒答率必须与误拒率一起看，这两件事的代价也完全不同：漏拒是幻觉，误拒是能力浪费——
所以分开报，不合成一个"准确率"。

**6. 「幻觉率」这个词必须带口径。** 本阶段量的是四类**可自动判定**的信号
（编号越界 / 参考文献编造或改写 / 数字查不到出处 / 该拒未拒）。措辞谨慎的事实性错误、
逻辑错误、临床不当推荐，本模块测不到。**「幻觉率 0」不等于「答案全对」。**

**7. 兜底边界默认关（`hard_refuse_on_all_irrelevant=False`）。** ①判定全部证据不相关时
直接改写成拒答，这在生产里是好兜底，但对抗测试要量的是**模型守不守约束**，
代码替它拒答会把这件事测没了。

**8. LLM 起草的对抗题不自动并入用例集。** 这些题的"期望行为"要人来定；
模型自己出题、自己判该不该拒答，没有独立性。`--llm-assist` 的草稿单独写到
`report_data\约束_对抗用例_llm草稿.json` 等人工审。

## 八、已知局限与下一步

**局限（如实说明）**

1. **只测得到可自动判定的幻觉**：编号越界 / 参考文献编造或改写 / 数字查不到出处 / 该拒未拒。
   措辞谨慎的事实性错误（证据说"可能相关"、答案写"可能有效"但方向反了）、逻辑错误、
   临床上的不当推荐，本模块**测不到**。「幻觉率 0」只意味着这四类信号没有命中。
2. **数字溯源有已知假阳性**：四舍五入（12.63% → 12.6%）、单位换算都会被记成"证据里查不到"。
   所以按 medium 报并列出原文供人核，不当作硬失败。
3. **事实句覆盖率是启发式**：程序分不出"断言句"与"转折句"，阈值 0.8 留得宽。
   本轮剩下的 2 条 `citation.missing` 都属于这一类（4 句里 1 句没挂出处）。
4. **拒答与部分作答用的是二值口径**，表达不了"先说答不全、再答可答的部分"这种正确行为——
   `adv-E1` 那条 FAIL 就是这么来的（见「三 4」）。
5. **规模小**：13 道题、单次采样，②段温度 0.3。**结论看方向与量级，不要引用小数点后两位。**
6. **基线组与阶段七不是逐字相同**：它走的是同一条主干代码、只关掉层 A/D，唯一差别是不再追加
   阶段七那段"⚠ 校验提示"（那段话不影响任何指标）。

**下一步**

1. **把"完全拒答"与"部分作答"分开计量**（本阶段最该先做的一件事，见「三 4」）。
2. **拿这套尺子回测提示词改动**：阶段八留下的靶子（`percentage`/`statistic` 类证据最容易被摘掉、
   中英混排 0.394）现在可以和本阶段的合规率一起，作为改提示词的闭环评价。
3. **扩用例集**：`--llm-assist` 已经能起草，缺的是人工审定期望行为；
   每类补到 8~10 道，指标才经得起小数点后两位。
4. **多轮修正的收益未测**：`--repair-rounds 2` 会不会把剩下的 `citation.missing` 修掉，
   还是只会来回改写，需要实测。
